THE PIXEL VAULT

E-commerce de videojuegos y merchandising con estética retro-futurista diseñado para que sientas que compras dentro de un videojuego. Desarrollado de extremo a extremo (Full Stack), combina una interfaz dinámica y altamente interactiva en el Frontend con una arquitectura sólida en el Backend para la gestión de productos, usuarios y flujo de compra en tiempo real.

The Pixel Vault es una tienda en línea de videojuegos digitales y merchandising (juguetes, pósters, ropa y accesorios) con una estética pixel-art y neón pensada para que comprar se sienta como jugar. El recorrido de compra está resuelto de punta a punta: un menú de navegación circular, registro e inicio de sesión, un catálogo de tarjetas con modal de detalle, un carrito con control de cantidades y un modal de pago con datos de envío y facturación, una sección «Mi cuenta» con avatar y métodos de pago, historial de pedidos y un formulario con validación para registrar productos. También incluye una página de contacto conectada a Formspree y modales de soporte con preguntas frecuentes, términos y política de privacidad, todo con diseño responsivo. El frontend está hecho con HTML, CSS, JavaScript y Bootstrap 5, diseñado previamente en Figma, y se conecta a una API en Java con Spring Boot y base de datos MySQL. Fue un proyecto de equipo con ramas por tarea y pull requests, lo que me permitió practicar el flujo de trabajo colaborativo de un desarrollo real.

RECOMENDACIONES DE PELÍCULAS

Una experiencia web dinámica desarrollada íntegramente en un solo archivo HTML. Este proyecto nació como un reto de arquitectura frontend para dominar el diseño One-Page, integrando múltiples niveles de carruseles anidados, ventanas modales y tarjetas interactivas. Una prueba real de ingenio, limpieza y orden estructural en la escritura de código.

«Fotogramas que permanecen» es un mini sitio de recomendaciones de películas pensado para cinéfilos y para quienes disfrutan de tramas interesantes y estilos cinematográficos distintos. La navegación parte de los géneros: al elegir uno aparecen las películas recomendadas dentro de tarjetas y carruseles, y al seleccionar una se abre un panel de detalle con director, elenco principal, vibes, clasificación y advertencias de contenido, sinopsis, puntuación en Rotten Tomatoes, el porqué de la recomendación, dónde verla, detalles técnicos y películas relacionadas. Está construido con HTML, CSS, Bootstrap y JavaScript, y fue un laboratorio para resolver problemas reales de frontend: un panel que congelaba la página, un menú hamburguesa que quedaba detrás del contenido y pósters que debían verse completos. Documenté el proceso, incluidos los prompts con los que me apoyé en IA para definir la idea y optimizar el CSS, y dejé comentarios en la hoja de estilos a modo de glosario para entender cada decisión.

GRYFFINDOR RESISTANCE

Landing page temática de la casa Gryffindor (Harry Potter) diseñada como una red social para estudiantes de magia durante un hackatón de un día. Desarrollé de forma individual todo el Frontend de la página de perfil integrada —una réplica estilo Facebook con banner, información, publicaciones y galería de fotos—, demostrando agilidad y dominio de maquetación UI en tiempo récord.

Gryffindor Resistance es un sitio temático de la casa Gryffindor, con paleta roja y dorada, construido en equipo durante un hackatón de un día. Presenta la historia de Godric Gryffindor, un carrusel con los personajes principales de la casa, un formulario de reclutamiento de voluntarios con validación —cuyos registros se guardan en el navegador y se muestran como tarjetas—, un catálogo visual de productos como bufandas, capas, uniformes y varitas, y una página de perfil que funciona como red social para estudiantes de magia. Mi aportación fue esa página de perfil: la desarrollé completa y de forma individual como una réplica al estilo Facebook, con banner, información personal, publicaciones y galería de fotos, cuidando el diseño responsivo con Bootstrap 5. Es una aplicación 100 % del lado del cliente, hecha con HTML, CSS y JavaScript, y un buen ejemplo de cómo coordinar interfaz, tiempos y decisiones de diseño con un equipo grande bajo una fecha límite de horas.

ENCUENTRA LAS PISTAS

Primera versión de mi portafolio personal, diseñada como una experiencia gamificada de búsqueda de pistas. Cada proyecto funciona como una habitación temática en la que el usuario debe descubrir 3 elementos ocultos para desbloquear la información técnica y visual, combinando narrativa creativa, JavaScript y diseño responsivo.

Esta fue la primera versión de mi portafolio y nació de una pregunta sencilla: ¿y si ver proyectos se sintiera como jugar? En lugar de una lista de enlaces, cada proyecto es una habitación temática que se explora: para abrir su información técnica y visual hay que encontrar tres elementos escondidos en la escena. Esa mecánica convierte la visita en una pequeña aventura, invita a mirar con atención y deja que cada proyecto cuente su historia antes de mostrar los detalles. Detrás hay narrativa creativa, ilustración y diseño pensados para cada habitación, JavaScript para controlar las pistas y el desbloqueo, y un diseño responsivo para que la experiencia funcione igual en computadora y en móvil. Es un proyecto personal hecho con HTML, CSS y JavaScript, y la base creativa de la que partió este portafolio.
